## 框架整体特性

1.  **开箱即用的分层架构**
    -   内置 `dao`、`handler`、`router`、`service`分层结构，遵循清晰的领域逻辑组织方式。
    -   清晰职责边界，可快速初始化业务。
2.  **Viper + TOML配置管理**
    -   提供强大的配置加载、自动刷新、环境配置支持、结构体绑定，默认即用。
3.  **API → Redis/MySQL 一站式 Trace 能力**
    -   内置 TradeID 调用链追踪，请求级 TraceID 自动贯穿
    -   Redis/MySQL 全链路结果日志输出
    -   支持敏感词忽略过滤，提高可观测性（可配置）
4.  **Goose 管理数据库版本**
    -   提供迁移工具，支持自动升级、降级和 schema版本管理。
5.  **统一 API 响应格式**
    -   标准化业务返回体
    -   支持响应 body 输出
    -   提供丰富的错误码体系
6.  **国际化 I18N 支持 + 热更新语言包**
    -   多语言 JSON 文件自动加载
    -   支持增量更新（仅更新有变动的语言文件）
    -   无需重启服务
    -   支持链式调用与回调事件 `fsnotify.Event`
7.  **统一抽象的 Service 与 DAO 层**
    -   方便 mock测试与单元测试隔离，保证业务逻辑可测试性。
    -   统一的依赖注入方式
8.  **可扩展自定义DAO**
    -   更灵活的数据库访问封装，适用于多种应用场景的存储层设计。
